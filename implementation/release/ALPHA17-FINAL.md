## Final-only corrections

The final source applies four evidence-tooling corrections without changing the governed runtime exercised by RC9:

1. Complete assistant-message tool arguments supersede filtered `tool_execution_start` arguments for the same physical call.
2. Rejected-then-corrected return preparations are counted as same-attempt mechanical repairs.
3. Windows Python/jsonschema probes use temporary source/result files rather than multiline `python -c`.
4. Response-ID redaction requires ID-like entropy and preserves ordinary identifiers such as `call_succeeded` and `call_reason_code`.

## Claim limits
