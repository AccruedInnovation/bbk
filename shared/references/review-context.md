# Review Context

Context integrity uses exact content roots, not path/size summaries. Inventory included, retrieval-only, untracked, ignored, generated, external, deleted, omitted, truncated, stale, unavailable, and redacted material. Required missing context blocks only affected assertions. Shard semantically, assign one primary owner per source item, and add cross-shard review when an assertion or interface spans shards.

The review context is one specialized ContextEdgeContract-equivalent. It must bind effective rendered instructions, tools/capabilities, authority, and result contract in addition to content. Context integrity does not imply model comprehension or correctness.
