# Review Assurance

The `AssuranceContract` defines exact proof obligations. A `ReviewManifest` compiles one review decision. A `ReviewContextManifest` proves available context. A `ReviewRun` records attempts, evidence, findings, dispositions, and aggregate result.

Applicability is `none`, `inline`, or `manifest`. Select the smallest sufficient logical lens set. Each assertion has one primary owner; overlap requires complementary-method rationale. Deterministic checks precede inferential review. Aggregation is non-averaging and keeps candidate, reviewer, context, environment, and infrastructure failures distinct.
