# Role Map

Planning roles own outcomes, boundaries, questions, architecture, work design, and assurance. Root and Territory Wayfinders delegate clusters of human-decision work through a logical Questioning Wayfinder, which prepares exact Question Guide context, manages branch continuity, and returns ADR-compatible packets. Execution orchestrators own sequencing, containment, workspace coordination, and escalation but not planning semantics. Workers mutate only their assigned scope. Validators inspect exact assertions against exact candidates and never repair or waive their findings. Logical roles are distinct from physical invocations: co-location is allowed only when it preserves authority, result, and independence boundaries. The smallest capable role owns each action; user authority remains reserved where required.
