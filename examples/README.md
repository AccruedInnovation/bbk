# Examples

Public examples should teach current BBK behavior without depending on internal Blueprint development history.

Preferred example categories:

- `minimal-project/` — proportional initialization and mostly inline work;
- `planned-feature/` — fit, decisions, interfaces, structure, slices, and work units;
- `review-and-evidence/` — assurance contract, context, receipts, findings, and dispositions;
- `recovery/` — durable state, interruption, candidate invalidation, and safe resumption.

Internal Blueprint dogfood belongs in the Blueprint project or a separate integration repository.
