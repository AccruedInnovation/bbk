# Review Assurance examples

These examples demonstrate BBK review records only. They do not invoke a model, mutate a candidate, or establish official Blueprint authority.

- `routine-inline.json` — no separate persisted manifest is required.
- `material-interface.json` — focused interface/evidence review.
- `consequential-recovery.json` — state/effect, recovery, intent, and independent review.
- `multi-shard-integration.json` — semantic shards plus cross-shard assertion.
- `blind-reassessment.json` — prior findings hidden by context policy.
- `targeted-closure.json` — exact finding and closure criteria supplied.
